# Chiranth K — Engineering Portfolio

Live site: https://chiranthck.github.io/chiranth-engineering-portfolio/

Single-page portfolio (`index.html`, no build step). Project photos live in `images/<project>/`; keep new photos under ~500 KB (about 1600 px on the long side).

To add a project: copy one `<article class="project">` block and its matching `<dialog>` in `index.html`, give the dialog a new id, and point the `data-open` attributes at it.
