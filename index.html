Phoenix: modular IoT fire protection device

Overview

Phoenix is a functional prototype of a modular fire protection device that combines real-time fire detection, directional water suppression and remote alerting in one self-contained unit. It is meant for places where installing a full sprinkler network isn't practical.

What it does

  • Detects fire in real time within an 80 cm radius
  • Positions its platform and aims the nozzle at the fire automatically
  • Delivers water effectively at 20–25 m
  • Sends remote alerts over IoT

Recognition

  • Best Final Year Project, MSRIT
  • Indian patent application 202541095803, published November 2025
  • Developed in collaboration with Vision Safety India

6-Day Split Tracker: training and nutrition app

The problem

Commercial trackers impose their own programs and put the useful parts behind a paywall. I wanted to define the split myself, have weight targets progress on performance rather than the calendar, and keep my own data. So I built an installable web app that works offline, syncs across phone and laptop, and replaced the spreadsheet I'd been keeping lifts in.

What it does

  • Custom programs: build each month's plan by naming days, adding exercises and setting reps per set. Each month stands alone, so a new training block is a new plan and past months stay on record.
  • Earned progression: log weight per set. The top-set target rises only once you hit it, and the app works back from it to suggest a weight for every earlier set.
  • Skipped sessions: time off is marked as skipped, so it isn't misread as a plateau.
  • Bottleneck analysis: stalled lifts month over month, strength-balance ratios between lifts, and bodyweight trend as a percentage of bodyweight.
  • Diet tracking: calorie and macro targets set from weekly body-composition readings, with meals logged by typing, speaking or photographing them.
  • Photo-to-macros: handles nutrition labels, food on a kitchen scale, whole foods and mixed plates, broken into per-item grams you can correct.
  • Integrations: a daily Telegram brief, a monthly Excel export with charts, and import of workout files from a Suunto watch.

Stack

Plain HTML, CSS and JavaScript with no framework or build step, hosted on Netlify. Supabase provides Postgres, authentication, file storage and Edge Functions (Deno/TypeScript). Anthropic's API powers the vision and review features, and a service worker provides offline support.

Engineering decisions

  • Security in the database: all 13 Postgres tables have row-level security, with every policy scoped to the signed-in user, so data separation is enforced by the database rather than application code.
  • No keys in the browser: every model call goes through an Edge Function that authenticates the user first.
  • Progression maths: the Epley formula estimates a one-rep max from the top set, then the app solves back for each set's rep count to suggest its weight.
  • Calorie targets: Katch-McArdle when body-fat percentage is known, since it accounts for lean mass, with Mifflin-St Jeor as the fallback.
  • Hand-written FIT parser: I wrote the Suunto binary file parser myself instead of using a library, so I could unit-test it against generated files rather than trust an unverifiable dependency.
  • In-app camera: Android was evicting the app from memory while the system camera was open, losing the photo and the user's place. I replaced the file input with an in-page getUserMedia viewfinder.

Next

Per-user rate limiting and onboarding before opening it to other people, and a packaged Android build if it's worth leaving the browser.

Optimizing radish yield with Taguchi and Grey Relational Analysis

Paper

Optimizing Radish Crop Yield Using a Combinatorial Taguchi–Grey Relational Analysis Approach. M. Shilpa, Chiranth K, Ann Xaviera Rego, Challa Srinivas Parthiv and Riya B. Department of Industrial Engineering and Management, Ramaiah Institute of Technology, Bengaluru.

Read the paper (PDF)

Why radish

Radish matures in three to four weeks, which makes it well suited to early planting and intercropping, yet it gets little research attention because it is treated as a minor crop. Finding the best mix of inputs is usually done by slow trial and error.

Method

A Taguchi L9 orthogonal array set out nine treatment combinations of three factors — seed variety, irrigation method and manure composition — applied to randomized plots with two replications each. That covers the effects with nine treatments instead of all 27 combinations. Yield was measured three ways: root length, number of radishes and weight. Grey Relational Analysis combined the three into a single grade to rank the treatments.

Results

  • Best combination: Trusted Seeds, drip irrigation and DAP manure, with a grey relational grade of 0.84, the highest of the nine treatments
  • Seed variety had the largest effect on yield, followed by manure composition, then irrigation method
  • Experiment: average root length 14.75 cm, quantity 35.5, weight 2.25 kg
  • Confirmation run on four plots: 14.82 cm, 36 radishes and 2.31 kg, closely matching the prediction

Maruti 800 electrical system mock layout

Overview

We designed and built a full-scale mock layout of the Maruti 800's electrical system, showing how the battery, charging system, starter, ignition, lighting and control circuits connect and interact.

Components

  • Power: battery, generator assembly, alternator
  • Engine: starter motor, distributor, spark plug
  • Lighting: headlights, tail lamps, indicators, interior light
  • Controls: combination switch, steering lock, relays
  • Monitoring: fuel gauge, multimeter
  • Safety: horn, wiper motor
